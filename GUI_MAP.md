# DTS GUI — map of the menus, steps and `dts_core` functions

Version 3.40, 16.11.2026.  Generated by a static analysis of `dts_steps.py` (the step functions and every helper they call), `dts_core.py` and `gui_figures.py`.

How to read the tables:

- **Step key**: the key in `dts_steps.STEPS`, run by the button of the panel (the `.replot` keys only redraw figures).
- **Panel inputs**: the parameters read from the panel (`p[...]`).
- **Session inputs**: the session variables the step reads but does not create.
- **Outputs**: the session variables the step writes (they appear in View → View all variables).
- **`dts_core` functions**: called directly by the step or its helpers; *indirect* = called inside those `dts_core` functions. `physics`, `eos_summary` and `check_cancel` are left out (physical parameters, log text, Interrupt button).
- **Figures**: the `gui_figures` functions used to draw the results.
- **Save data** (right click on any figure name): `gui_export.figure_data` + `gui_export.write`, the same for every figure.

## Menu Advanced

### Physical parameters…  (window, not a step)

`gui_physics.PhysicsDialog`, built from `dts_core.PHYSICAL_PARAMETERS`; it writes `dts_core.PHYSICS` through `dts_core.set_physics`. Every step reads the values with `dts_core.physics(name)` (directly or through `density`, `thermal_expansion`, `reduced_gravity`, `coriolis_frequency_Hz`, `brunt_vaisala`, `sound_speed_matrix`).

### Save variables…  (window, not a step)

`gui_variables.SaveVariablesDialog`: tick list of `session.data` and of `dts_core.PHYSICS`; writes with `gui_export.to_tree` + `gui_export.write` (npz, NetCDF, HDF5, txt, csv, MATLAB). No `dts_core` computation.
